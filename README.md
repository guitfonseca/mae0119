# Estatística em 7 dias — MAE0119

Apostila de estudo para MAE0119 (Introdução à Probabilidade e à Estatística II, IME-USP), organizada em um plano de 7 dias:

1. Distribuição Normal e Chebyshev
2. Variáveis contínuas: Uniforme e Exponencial
3. Distribuições bivariadas (conjunta, marginal, condicional, independência)
4. Soma de variáveis e Normal bivariada
5. Estimadores e Teorema Limite Central
6. Intervalos de confiança (média com z e t, proporção, tamanho de amostra)
7. Revisão: guia de qual fórmula usar na prova

Cada capítulo traz intuição, fórmulas, exemplos resolvidos passo a passo e exercícios das listas com resposta escondida. Inclui uma calculadora da Normal para conferir contas e um checklist de progresso salvo no navegador.

## Como abrir

É um único arquivo, `index.html`. Abra direto no navegador ou publique com GitHub Pages:

1. Suba `index.html` e este `README.md` para um repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. A página fica em `https://<seu-usuario>.github.io/<nome-do-repo>/`.

As fórmulas usam MathJax e as fontes vêm do Google Fonts, então é preciso internet para a página aparecer completa.
